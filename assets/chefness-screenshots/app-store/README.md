# Chefness App Store screenshot set

These five screenshots are prepared for the iPhone 6.9-inch App Store Connect
slot at **1290 × 2796 px**, portrait PNG, RGB, with no alpha channel.

## Recommended upload order

1. `01-ai-cooking-guru.png` — **Your personal AI cooking guru**
2. `02-adapt-recipes-with-ai.png` — **Adapt any recipe with AI**
3. `03-made-for-how-you-eat.png` — **Made for the way you eat**
4. `04-remember-every-meal.png` — **Remember every meal**
5. `05-choose-your-ai.png` — **Choose the AI that fits you**

The first three are intentionally the strongest value propositions because up
to three portrait screenshots may appear in App Store search results when no
app preview is present.

## Design rationale

- Each image leads with one short, benefit-focused message.
- Real in-app UI remains the dominant content and demonstrates the claimed
  feature.
- The set follows a user story: ask for help, adapt a recipe, personalize the
  assistant, remember meals, then choose an AI model.
- The cream, espresso, and saffron treatment matches the app rather than
  introducing a separate campaign style.
- The source captures in the parent directory remain unchanged.

## Apple guidance used

- Apple allows one to ten screenshots and accepts 1290 × 2796 portrait images
  for the 6.9-inch iPhone display slot.
- Screenshots must show the app in use; text and image overlays are allowed.
- Apple recommends leading with the strongest features and using subsequent
  screenshots to communicate one main benefit or feature each.
- Screenshots must not contain an alpha channel or transparency.

## Production note

The marketing variants were created with the built-in image-generation/editing
workflow, using the original screenshots as edit targets and requiring the UI
to remain truthful. Before uploading, compare the visible UI against the final
release build and recapture/regenerate any frame if product text or behavior has
changed.
